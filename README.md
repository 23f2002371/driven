# Student Club Website - Frontend Setup Guide 🚀

Welcome to the frontend repository for the Student Club website! 

If you've never run a coding project on your computer before, don't panic. This guide is written so that anyone can get the website running in just a few minutes. Just follow these steps in order!

## 🛠️ Step 1: Install the "Engine" (Node.js)
To run this project, your computer needs a software called **Node.js**. Think of it as the engine that powers our code.

1. Go to the official Node.js website: [https://nodejs.org/](https://nodejs.org/)
2. Download the version that says **"LTS" (Long Term Support)**. It will automatically detect if you are on a Mac or Windows.
3. Open the downloaded file and install it just like you would any normal program (keep clicking "Next" or "Continue" until it's done).

## 💻 Step 2: Install Visual Studio Code (VS Code)
We need a program to view our code. VS Code is the best tool for this.
1. Go to [https://code.visualstudio.com/](https://code.visualstudio.com/)
2. Download and install it for your Mac or Windows computer.

## 📥 Step 3: Get the Project on Your Computer
You need to bring the code from this website (GitHub) onto your personal computer.

**The easiest way:**
1. At the top right of this GitHub page, click the green **"<> Code"** button.
2. Click **"Download ZIP"**.
3. Once downloaded, **extract/unzip** the folder. 
4. Move this unzipped folder to your Desktop (or somewhere easy to find).

## 🔌 Step 4: Open the Project
1. Open **Visual Studio Code**.
2. Go to the top menu and click **File > Open Folder...** (On Mac, it's just **File > Open...**).
3. Find the project folder you unzipped in Step 3 and select it. 

## 📦 Step 5: Download the "Puzzle Pieces"
Our project relies on some external code files to work. We need to tell the computer to download them.

1. In VS Code, look at the very top menu bar and click **Terminal > New Terminal**.
2. A small window will pop up at the bottom of your screen. This is where we type commands.
3. Click inside that bottom window, type the following command exactly as it appears, and press **Enter** (or Return):

   ```bash
   npm install

#### Note: You will see a bunch of text scrolling by. This is normal! It's just your computer downloading the missing puzzle pieces it needs to run the site.

## 🏃‍♂️ Step 6: Start the Website!
Once the downloading stops and you can type in the terminal again, it's time to turn the website on.

1. In that same bottom terminal window, type this command and press Enter:
   
```npm run dev```


2. After a second or two, you will see a message pop up in the terminal that looks something like this:
```➜  Local:   http://localhost:5173/```

3. Hold down the ```Ctrl``` key (Windows) or ```Cmd ⌘``` key (Mac) and visit [http://localhost:5173](http://localhost:5173).

### 🎉 Congratulations! Your web browser will open, and you should now see the Student Club website running live on your computer!

## 🛑 How to turn it off
When you are done looking at the website, go back to VS Code, click inside the terminal window at the bottom, and press Ctrl + C. This turns the "engine" off. Next time you want to see the website, just open the folder in VS Code again and repeat Step 6.
